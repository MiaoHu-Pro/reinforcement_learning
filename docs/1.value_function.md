This loop computes the discounted return from the complete episode:

```python
for r in episode_rewards[::-1]:
    G = r + gamma * G
```

Suppose the rewards are:

```python
episode_rewards = [R_0, R_1, R_2, R_3]
```

The return from the initial state is:

$
G_0 = R_0 + \gamma R_1 + \gamma^2 R_2 + \gamma^3 R_3
$

The code calculates this efficiently by processing the rewards backward.

### Why process backward?

```python
episode_rewards[::-1]
```

creates a reversed sequence:

```python
[R_3, R_2, R_1, R_0]
```

Starting with:

```python
G = 0
```

each iteration calculates:
$
G_t = R_t + \gamma G_{t+1}
$
For example, with:

```python
episode_rewards = [1, 1, 1]
gamma = 0.9
```

the loop performs:

```text
Last reward:   G = 1 + 0.9 × 0    = 1
Second reward: G = 1 + 0.9 × 1    = 1.9
First reward:  G = 1 + 0.9 × 1.9  = 2.71
```

Therefore:

$
G_0 = 1 + 0.9 + 0.9^2 = 2.71
$

### Why use a discount factor?

`gamma` determines how important future rewards are:

- `gamma = 0`: only the immediate reward matters.
- `gamma = 0.9`: future rewards matter, but progressively less.
- `gamma = 1`: all rewards have equal weight.

### Relationship to the value function

This code calculates one sampled return, $G_0$, from one episode. It does not directly calculate the true value function.

The state-value function is:

$
V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t=s]
$

In words: the value of state $s$ is the expected return when starting from that state and following policy $\pi$.

Because one episode gives only one sample, $G_t$ can be used as a Monte Carlo estimate of $V^\pi(S_t)$. To estimate the value function reliably, you would usually collect many episodes and average their returns for each visited state.

### Computing the return for every time step

The existing loop retains only the final value, $G_0$. To calculate all returns—$G_0, G_1, \ldots$—store them:

```python
G = 0.0
returns = []

for reward in reversed(episode_rewards):
    G = reward + gamma * G
    returns.append(G)

returns.reverse()
```

For rewards `[1, 1, 1]` and `gamma = 0.9`, this produces:

```python
returns == [2.71, 1.9, 1.0]
```

These correspond to:

```text
G_0 = 2.71
G_1 = 1.90
G_2 = 1.00
```
